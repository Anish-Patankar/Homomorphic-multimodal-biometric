STEP 1: EXTRACT FEATURES FOR A SINGLE IRIS IMAGE
--------------------------------------------------------------------------------
Syntax:
  java -cp "<classpath>" IrisFeatureExtractor <image_path> <output_json> <subject_id> <sample_id> [dataset_name] [subdataset_name]

Arguments:
  1. image_path       : Path to input image (.bmp, .png, .jpg, etc.)
  2. output_json      : Destination JSON file
  3. subject_id       : Identifier of the subject (e.g. "001")
  4. sample_id        : Identifier of the sample/image (e.g. "01")
  5. dataset_name     : (Optional) Label for dataset (e.g. "IIT_Iris", default: "IrisDataset")
  6. subdataset_name  : (Optional) Side or partition (e.g. "Left", "Right", default: "Default")

Example Command:
[PowerShell]
& "C:\Program Files\Java\jdk-25.0.4.1\bin\java.exe" -cp "src;C:\Program Files\Neurotechnology\Neurotec_Biometric_2025_2_SDK\Bin\Java\*" IrisFeatureExtractor "images\02.bmp" "templates\test_output.json" "001" "02" "IIT_Iris" "Left"

[CMD / Command Prompt]
"C:\Program Files\Java\jdk-25.0.4.1\bin\java.exe" -cp "src;C:\Program Files\Neurotechnology\Neurotec_Biometric_2025_2_SDK\Bin\Java\*" IrisFeatureExtractor "images\02.bmp" "templates\test_output.json" "001" "02" "IIT_Iris" "Left"

Verify Generated Output:

STEP 2: BATCH FEATURE EXTRACTION FOR A FULL DATABASE
--------------------------------------------------------------------------------

Supported Dataset Folder Conventions:
  A) Subject & Eye side subfolders (e.g. IIT Iris):
       <database_root>\<SubjectSide>\<sample>.bmp
       Example: "IIT iris seperated\001left\01.bmp"
                "IIT iris seperated\001right\06.bmp"

  B) Subject folders:
       <database_root>\Subject_<N>\<sample>.bmp
       Example: "Database\Subject_001\1.bmp"

Output Files Generated Per Sample:
  - <output_root>\<SubjectSide>\<sample>.json (contains metadata, contours, feature_vector_binary bitstring, and feature_vector_base64)
  - <output_root>\<SubjectSide>\<sample>.bin  (companion raw 5,184-byte binary file for direct binary loading)
  Example:
    "Iris_Features\001left\01.json"
    "Iris_Features\001left\01.bin"


--- METHOD A: Using the Python Batch Script (Recommended) ---

1. Preview / Dry-Run (Discovers images without executing extraction):
   python extract_iris_features.py "IIT iris seperated" Iris_Features --dry-run

2. Run Full Batch Extraction:
   python extract_iris_features.py "IIT iris seperated" Iris_Features --dataset IIT_Iris --skip-existing

Flags:
  --dataset NAME     : Sets dataset metadata field (default: IrisDataset)
  --skip-existing    : Skips images that already have a generated JSON
  --dry-run          : Scans dataset and prints mappings without extracting
  --legacy-workers   : Runs multiple separate JVM processes in parallel
  --jobs N           : Number of parallel workers when using --legacy-workers

STEP 6 - FACE FAR/FRR EVALUATION (FaceFarFrrEvaluator)
================================================================================
Source:        src\FaceFarFrrEvaluator.java
Output folder: face_evaluation_results\

NOTE: jna.library.path is set inside the Java code — do NOT add -Djna.library.path
      as a JVM flag; the backtick line-continuation trick breaks the command.

1. Build classpath variable (run once per PowerShell session):

[PowerShell]
$JDIR = "C:\Program Files\Neurotechnology\Neurotec_Biometric_2025_2_SDK\Bin\Java"
$CP   = (Get-ChildItem "$JDIR\*.jar" | Where-Object { $_.Name -notlike "*javadoc*" } | ForEach-Object { $_.FullName }) -join ";"

2. Compile:

[PowerShell]
javac -cp "$CP" src\FaceFarFrrEvaluator.java -d out\

[CMD / Command Prompt]
"C:\Program Files\Java\jdk-25.0.4.1\bin\javac.exe" -cp "C:\Program Files\Neurotechnology\Neurotec_Biometric_2025_2_SDK\Bin\Java\*" src\FaceFarFrrEvaluator.java -d out\

3. Run (evaluate lfw_features -> face_evaluation_results):

[PowerShell]
java -cp "out;$CP" FaceFarFrrEvaluator lfw_features face_evaluation_results

[CMD / Command Prompt]
"C:\Program Files\Java\jdk-25.0.4.1\bin\java.exe" -cp "out;C:\Program Files\Neurotechnology\Neurotec_Biometric_2025_2_SDK\Bin\Java\*" FaceFarFrrEvaluator lfw_features face_evaluation_results

4. Custom paths:
   java -cp "out;$CP" FaceFarFrrEvaluator <features_dir> <output_report_dir>

Files Generated:
  - face_evaluation_results\face_far_frr_report.txt   (full text report with EER, operating points)
  - face_evaluation_results\face_roc_curve.csv        (Threshold, FAR, FRR, GAR for every score value)
  - face_evaluation_results\face_genuine_scores.csv   (per-pair genuine match scores)
  - face_evaluation_results\face_impostor_scores.csv  (per-pair impostor match scores)

Pairing logic:
  - Genuine : all combinations of .bin files within the same person subfolder
  - Impostor: first .bin of every pair of different person subfolders
